# Установить Расширение Браузера

Расширение AiShort (Chat instructions) помогает вам вызывать библиотеку промптов AIShort в любое время, повышая эффективность работы и обучения. Поддерживает основные браузеры, такие как Chrome, Edge, Firefox, и предоставляет функции боковой панели и горячих клавиш. Вы можете быстро вызвать расширение с помощью `Alt + Shift + S`.

## 🧩 Скрипт Tampermonkey

Помимо формата расширения, мы также предоставляем [**Скрипт Tampermonkey Chat instructions Anywhere**](https://greasyfork.org/scripts/482907-chatgpt-shortcut-anywhere).
Tampermonkey - это расширение браузера, которое позволяет пользователям запускать пользовательские скрипты для улучшения функций веб-страниц.

С помощью этого скрипта вы можете вызывать боковую панель AiShort на любом веб-сайте.
Однако, из-за ограничений официальной страницы ChatGPT на инъекцию скриптов, на этой странице скрипт будет работать как **всплывающее окно** вместо боковой панели.
