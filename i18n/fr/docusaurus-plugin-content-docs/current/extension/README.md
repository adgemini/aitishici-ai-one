# Installer l'extension de navigateur

L'extension AiShort (Chat instructions) vous aide à invoquer la bibliothèque de prompts AIShort à tout moment, améliorant l'efficacité du travail et de l'étude. Prend en charge les navigateurs courants comme Chrome, Edge, Firefox, et fournit des fonctions de barre latérale et de raccourcis. Vous pouvez invoquer rapidement l'extension via `Alt + Shift + S`.

## 🧩 Script Tampermonkey

En plus du format d'extension, nous fournissons également le [**Script Tampermonkey Chat instructions Anywhere**](https://greasyfork.org/scripts/482907-chatgpt-shortcut-anywhere).
Tampermonkey est une extension de navigateur qui permet aux utilisateurs d'exécuter des scripts personnalisés pour améliorer les fonctions des pages web.

Avec ce script, vous pouvez invoquer la barre latérale AiShort sur n'importe quel site web.
Cependant, en raison des restrictions de la page officielle de ChatGPT sur l'injection de scripts, sur cette page, le script s'exécutera sous forme de **fenêtre contextuelle** au lieu d'une barre latérale.
