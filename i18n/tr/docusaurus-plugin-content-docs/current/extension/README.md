# Tarayıcı Uzantısını Yükle

AiShort (Chat instructions) uzantısı, AIShort prompt kütüphanesine her zaman erişmenizi sağlar, iş ve çalışma verimliliğini artırır. Chrome, Edge, Firefox gibi ana tarayıcıları destekler ve kenar çubuğu ve kısayol özellikleri sunar. Uzantıyı `Alt + Shift + S` ile hızlıca çağırabilirsiniz.

## 📥 Resmi İndirme Kanalları

- **Chrome**: [Chrome Web Store](https://chrome.google.com/webstore/detail/chatgpt-shortcut/blcgeoojgdpodnmnhfpohphdhfncblnj)
- **Edge**: [Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/chatgpt-shortcut/hnggpalhfjmdhhmgfjpmhlfilnbmjoin)
- **Firefox**: [Firefox Browser ADD-ONS](https://addons.mozilla.org/addon/chatgpt-shortcut/)
- **GitHub**: [GitHub Release](https://github.com/rockbenben/Chat-instructions/releases/latest)

## 🧩 Tampermonkey Script

Uzantıya ek olarak, [**Chat instructions Anywhere Tampermonkey Script**](https://greasyfork.org/scripts/482907-chatgpt-shortcut-anywhere) de sunuyoruz.
Tampermonkey, kullanıcıların web sayfası işlevlerini geliştirmek için özel scriptler çalıştırmasına izin veren bir tarayıcı uzantısıdır.

Bu script ile herhangi bir web sitesinde AiShort kenar çubuğunu çağırabilirsiniz.
