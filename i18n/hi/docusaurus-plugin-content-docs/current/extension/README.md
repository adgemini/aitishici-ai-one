# ब्राउज़र एक्सटेंशन इंस्टॉल करें

AiShort (Chat instructions) एक्सटेंशन आपको किसी भी समय AIShort प्रॉम्प्ट लाइब्रेरी तक पहुँचने में मदद करता है, जिससे कार्य और अध्ययन दक्षता में सुधार होता है। यह Chrome, Edge और Firefox जैसे मुख्यधारा के ब्राउज़रों का समर्थन करता है, और साइडबार और शॉर्टकट सुविधाएँ प्रदान करता है। आप प्लगइन को जल्दी से सक्रिय करने के लिए `Alt + Shift + S` का उपयोग कर सकते हैं।

## 📥 आधिकारिक डाउनलोड चैनल

- **Chrome**: [Chrome Web Store](https://chrome.google.com/webstore/detail/chatgpt-shortcut/blcgeoojgdpodnmnhfpohphdhfncblnj)
- **Edge**: [Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/chatgpt-shortcut/hnggpalhfjmdhhmgfjpmhlfilnbmjoin)
- **Firefox**: [Firefox Browser ADD-ONS](https://addons.mozilla.org/addon/chatgpt-shortcut/)
- **GitHub**: [GitHub Release](https://github.com/rockbenben/Chat-instructions/releases/latest)
- **मिरर डाउनलोड (स्टोर के अप्राप्य होने पर उपयोग करें)**: [Alist Cloud](https://alist.newzone.top:9003/apps/ChatGPT%20Shortcut%20Extension); [Lanzou Cloud (पासवर्ड: 1qow)](https://wwva.lanzouq.com/b01lsc9vi)

## 🧩 टैम्परमंकी स्क्रिप्ट (Tampermonkey Script)

एक्सटेंशन फॉर्म के अलावा, हम [**Chat instructions Anywhere Script**](https://greasyfork.org/scripts/482907-chatgpt-shortcut-anywhere) भी प्रदान करते हैं।
टैम्परमंकी एक ब्राउज़र एक्सटेंशन है जो उपयोगकर्ताओं को वेब पेज की कार्यक्षमता बढ़ाने के लिए कस्टम स्क्रिप्ट चलाने की अनुमति देता है।

इस स्क्रिप्ट के माध्यम से, आप किसी भी वेबसाइट पर AiShort साइडबार ला सकते हैं।
हालाँकि, कृपया ध्यान दें कि आधिकारिक ChatGPT पृष्ठ पर स्क्रिप्ट इंजेक्शन प्रतिबंधों के कारण, उस पृष्ठ पर स्क्रिप्ट साइडबार के बजाय **पॉपअप** के रूप में चलेगी।
