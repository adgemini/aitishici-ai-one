# Installa Estensione Browser

L'estensione AiShort (Chat instructions) ti aiuta a invocare la libreria di prompt AIShort in qualsiasi momento, migliorando l'efficienza nel lavoro e nello studio. Supporta i browser mainstream come Chrome, Edge, Firefox, e fornisce funzioni di barra laterale e scorciatoie. Puoi invocare rapidamente l'estensione tramite `Alt + Shift + S`.

## 🧩 Script Tampermonkey

Oltre al formato estensione, forniamo anche lo [**Script Tampermonkey Chat instructions Anywhere**](https://greasyfork.org/scripts/482907-chatgpt-shortcut-anywhere).
Tampermonkey è un'estensione del browser che permette agli utenti di eseguire script personalizzati per migliorare le funzioni delle pagine web.

Con questo script, puoi invocare la barra laterale AiShort su qualsiasi sito web.
Tuttavia, a causa delle restrizioni della pagina ufficiale di ChatGPT sull'iniezione di script, su quella pagina lo script verrà eseguito come un **popup** invece di una barra laterale.
