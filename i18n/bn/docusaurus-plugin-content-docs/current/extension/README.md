# ব্রাউজার এক্সটেনশন ইনস্টল করুন

AiShort (Chat instructions) এক্সটেনশন আপনাকে যেকোনো সময় AIShort প্রম্পট লাইব্রেরি অ্যাক্সেস করতে সাহায্য করে, যা কাজ এবং অধ্যয়নের দক্ষতা উন্নত করে। এটি Chrome, Edge এবং Firefox এর মতো মূলধারার ব্রাউজারগুলি সমর্থন করে এবং সাইডবার এবং শর্টকাট বৈশিষ্ট্যগুলি অফার করে। আপনি প্লাগইনটি দ্রুত সক্রিয় করতে `Alt + Shift + S` ব্যবহার করতে পারেন।

## 📥 অফিসিয়াল ডাউনলোড চ্যানেল

- **Firefox**: [Firefox Browser ADD-ONS](https://addons.mozilla.org/addon/chatgpt-shortcut/)
- **GitHub**: [GitHub Release](https://github.com/rockbenben/Chat-instructions/releases/latest)
- **মিরর ডাউনলোড (স্টোর অ্যাক্সেসযোগ্য না হলে ব্যবহার করুন)**: [Alist Cloud](https://alist.newzone.top:9003/apps/ChatGPT%20Shortcut%20Extension); [Lanzou Cloud (পাসওয়ার্ড: 1qow)](https://wwva.lanzouq.com/b01lsc9vi)

## 🧩 ট্যাম্পারমাঙ্কি স্ক্রিপ্ট (Tampermonkey Script)

এক্সটেনশন ফর্ম ছাড়াও, আমরা [**Chat instructions Anywhere Script**](https://greasyfork.org/scripts/482907-chatgpt-shortcut-anywhere) ও প্রদান করি।
ট্যাম্পারমাঙ্কি একটি ব্রাউজার এক্সটেনশন যা ব্যবহারকারীদের ওয়েব পৃষ্ঠার কার্যকারিতা বাড়াতে কাস্টম স্ক্রিপ্ট চালানোর অনুমতি দেয়।

এই স্ক্রিপ্টের মাধ্যমে, আপনি যেকোনো ওয়েবসাইটে AiShort সাইডবার আনতে পারেন।
যাইহোক, দয়া করে মনে রাখবেন যে অফিসিয়াল ChatGPT পৃষ্ঠায় স্ক্রিপ্ট ইনজেকশন বিধিনিষেধের কারণে, সেই পৃষ্ঠায় স্ক্রিপ্টটি সাইডবারের পরিবর্তে **পপআপ** হিসেবে চলবে।
