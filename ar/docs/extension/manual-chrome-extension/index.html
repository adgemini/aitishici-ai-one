دليل التثبيت المحلي لإضافة Chrome CRX

تنزيل حزمة تثبيت CRX​

قم بتنزيل حزمة تثبيت crx لـ Chat instructions (ChatGPT_Shortcut-crx-3.x.x.zip)، وقم بفك ضغطها (ملف crx موجود في المجلد الذي تم فك ضغطه).

  • GitHub: GitHub Release
  • التنزيل المحلي: Alist Cloud; Lanzou Cloud، كلمة المرور: 1qow

تمكين وضع المطور​

افتح صفحة "إدارة الإضافات" في Chrome، وقم بتشغيل "وضع المطور".

انسخ العنوان أدناه والصقه في شريط عنوان المتصفح، واضغط على Enter لفتحه. قم بتشغيل "وضع المطور" في الزاوية العلوية اليمنى من الصفحة.

chrome://extensions

تثبيت المكون الإضافي​

قم بتثبيت المكون الإضافي Chat instructions (ملاحظة ⚠️: تحتاج إلى سحب ملف .crx، لا تنقر فوق [تحميل تم فك حزمه])

بعد التثبيت الناجح، يمكنك عرض برنامج تعليمي لاستخدام الإضافة.

تواجه مشاكل في التثبيت؟​

  1. مستخدمو Windows، يرجى التحقق مما إذا كنت قد قمت بفك ضغط حزمة التثبيت التي تم تنزيلها (بدلاً من النقر المزدوج)؟

  2. هل "وضع المطور" قيد التشغيل؟ إذا لم يكن كذلك، يرجى الرجوع إلى الخطوة الثانية.

  3. هل قمت بسحب ملف crx إلى صفحة "الإضافات"؟ ملاحظة ⚠️: لا تنقر فوق [تحميل تم فك حزمه]، يجب عليك سحب ملف crx.

  4. المتصفح لا يسمح بتثبيت ملفات crx؟ جرب تثبيت ملف مضغوط! انقر هنا لعرض برنامج تعليمي لتثبيت ZIP.
