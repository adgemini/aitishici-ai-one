## ทำไมต้องใช้ AI one?

AI one (Chat instructions) รวบรวมรายชื่อ AI prompts ที่คัดสรรมาแล้ว ช่วยให้คุณค้นหา prompt สำหรับทุกสถานการณ์ได้อย่างรวดเร็ว

### ฟีเจอร์หลัก

🚀 **One-Click Prompts** - Prompts มืออาชีพที่คัดสรรมาแล้ว คลิกเดียวเพื่อคัดลอกและใช้งาน

🔍 **Smart Search** - ค้นหา prompts ได้รวดเร็วด้วยการกรองแท็กและค้นหาคำหลัก

🌍 **18 ภาษา** - มีคำแปลสำหรับทุก prompt พร้อมการตอบกลับในภาษาท้องถิ่น

📦 **พร้อมใช้งาน** - ไม่ต้องลงทะเบียน เริ่มใช้งานได้ทันที

### ฟีเจอร์ขั้นสูง (ต้องเข้าสู่ระบบ)

📂 **My Collection** - บันทึก prompts ที่ชอบ พร้อมการเรียงลำดับแบบลากและวาง และแท็กที่กำหนดเอง

✏️ **Custom Prompts** - สร้าง แก้ไข และจัดการ prompts ของคุณเอง

🗳️ **Community** - แบ่งปัน prompts และโหวตผลงานจากชุมชน

📤 **Export** - สำรองข้อมูล prompts ทั้งหมดของคุณเป็นไฟล์ JSON

🔐 **ตัวเลือกการเข้าสู่ระบบที่หลากหลาย** - รหัสผ่าน, Google, หรือลิงก์อีเมลแบบไม่ต้องใช้รหัสผ่าน

## ส่วนขยายเบราว์เซอร์

เข้าถึง prompts ของ AI one ได้ทุกที่ด้วยส่วนขยายเบราว์เซอร์ รองรับ Chrome, Edge, และ Firefox พร้อมแถบด้านข้างที่เปิดด้วย `Alt + Shift + S`

- **Chrome**: [Chrome Web Store](https://chrome.google.com/webstore/detail/chatgpt-shortcut/blcgeoojgdpodnmnhfpohphdhfncblnj)
- **Edge**: [Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/chatgpt-shortcut/hnggpalhfjmdhhmgfjpmhlfilnbmjoin)
- **Firefox**: [Firefox Add-ons](https://addons.mozilla.org/addon/chatgpt-shortcut/)
- **GitHub**: [Releases](https://github.com/rockbenben/Chat-instructions/releases/latest)

นอกจากนี้เรายังมีสคริปต์ Tampermonkey [Chat instructions Anywhere](https://greasyfork.org/scripts/482907-chatgpt-shortcut-anywhere) สำหรับใช้งานแถบด้านข้าง AI one บนเว็บไซต์ใดก็ได้

## การติดตั้ง

ติดตั้งอินสแตนซ์ของคุณเองผ่าน Vercel, Cloudflare Pages, Docker หรือแบบ local ดู [คู่มือการติดตั้ง](https://www.onebiu.cn/th/docs/deploy)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Frockbenben%2FChat-instructions%2Ftree%2Fmain)

## อัปเดตข้อมูล

หากคุณติดตั้งผ่าน Vercel แบบคลิกเดียว คุณอาจเห็นการแจ้งเตือนอัปเดตอย่างต่อเนื่อง สิ่งนี้เกิดขึ้นเพราะ Vercel สร้างโปรเจกต์ใหม่แทนที่จะทำการ fork วิธีแก้ไข:

1. ลบ repository ที่มีอยู่
2. Fork โปรเจกต์นี้โดยใช้ปุ่ม "Fork"
3. ติดตั้งใหม่บน [Vercel](https://vercel.com/new) โดยใช้ fork ของคุณ

### อัปเดตอัตโนมัติ

หลังจาก fork, เปิดใช้งาน Workflows ในหน้า Actions และเปิดใช้งาน Upstream Sync Action เพื่ออัปเดตอัตโนมัติทุกวัน

![Auto Updates](https://img.newzone.top/2023-05-19-11-57-59.png?imageMogr2/format/webp)

### อัปเดตด้วยตัวเอง

ดู [เอกสาร GitHub](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/syncing-a-fork) สำหรับการซิงค์ forks
