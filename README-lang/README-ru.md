## ⚡ Быстрый старт

1. Посетите [onebiu.cn](https://www.onebiu.cn/ru/)
2. Найдите или просмотрите нужный промпт
3. Нажмите «Копировать» и вставьте в любую ИИ-модель

![AI one Interface](../static/img/docs/interface-home.png)

Вот и всё! Подробнее в [Руководстве пользователя](https://www.onebiu.cn/ru/docs/guides/getting-started).

## Почему AI one?

AI one (Chat instructions) предлагает тщательно подобранный список ИИ-промптов, помогая быстро найти подходящие промпты для любой ситуации.

### Основные функции

🚀 **Промпты в один клик** - Отборные профессиональные промпты, один клик для копирования и использования.

🔍 **Умный поиск** - Быстрый поиск с фильтрами тегов и ключевыми словами.

🌍 **18 языков** - Переводы для всех промптов, ответы на родном языке.

📦 **Готово к использованию** - Регистрация не требуется, начните сразу.

### Расширенные функции (требуется вход)

📂 **Моя коллекция** - Сохраняйте избранное с сортировкой перетаскиванием и пользовательскими тегами.

✏️ **Свои промпты** - Создавайте, редактируйте и управляйте собственными промптами.

🗳️ **Сообщество** - Делитесь промптами и голосуйте за вклад других.

📤 **Экспорт** - Резервное копирование всех промптов в JSON.

🔐 **Несколько способов входа** - Пароль, Google или ссылка по email.

## Расширение для браузера

Доступ к промптам AI one в любое время. Поддержка Chrome, Edge и Firefox с боковой панелью через `Alt + Shift + S`.

- **Chrome**: [Chrome Web Store](https://chrome.google.com/webstore/detail/chatgpt-shortcut/blcgeoojgdpodnmnhfpohphdhfncblnj)
- **Edge**: [Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/chatgpt-shortcut/hnggpalhfjmdhhmgfjpmhlfilnbmjoin)
- **Firefox**: [Firefox Add-ons](https://addons.mozilla.org/addon/chatgpt-shortcut/)
- **GitHub**: [Releases](https://github.com/rockbenben/Chat-instructions/releases/latest)
